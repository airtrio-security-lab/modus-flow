# Платформа: правила (PostgreSQL + RLS, TypeScript без сборки)

- Изоляция организаций — на уровне базы: RLS и составные внешние ключи (ADR-0002). Сервер ходит под непривилегированной ролью; запрос без контекста организации не должен ничего вернуть.
- TypeScript исполняется Node без сборки (ADR-0005): только стираемый синтаксис — без `enum`, без свойств-параметров конструктора, без `namespace`. Импорты с расширением `.ts`. На границе — zod.
- Инварианты процесса живут в базе (ADR-0010). Нельзя обойти их в коде сервиса.
- Никто не принимает финальное решение по своей идее. С началом полевой проверки — двое разных людей. Отложить решение может только ответственный за решение; пока отложено, срок на паузе.
- XP и уровни начисляет база только за подтверждённые события; замок растёт только от внедрённых идей.
- Изменение схемы — новая миграция с очередным номером; применённые миграции не правятся.
- Тесты платформы никогда не пропускаются: без `TEST_DATABASE_URL` проверка останавливается. Тесты без базы добавляются в быстрый шаг `scripts/verify.sh`.
- Текст пользователей не попадает в уведомления и журнал аудита (ADR-0008); персональные данные в знаниях — по ADR-0018.
- Демо-вход и dev-токены — только для локального показа, никогда с реальными данными (ADR-0009).
