# ADR-0024. Облачная языковая модель (Anthropic, OpenAI) и AI-Архивариус

Дата: 2026-11-12 · Статус: принято (ветка `feat/kingdom-map`) · Решение владельца от 12.11.2026: подключить облачную модель; начать с Claude Haiku на пробные средства Anthropic.

## Что изменилось
До этого MODUS ADVISOR мог работать только с локальной моделью (ADR-0013): текст не покидал компьютер, платных сервисов не было. Владелец разрешил облачную модель. Теперь провайдер один из: `none` (по умолчанию), `ollama`, `anthropic`, `openai`.

## Правила включения
Облачная модель запускается только при явных переключателях — иначе сервер не стартует и объясняет, чего не хватает:

| Переменная | Зачем |
| --- | --- |
| `MODUS_ADVISOR_PROVIDER=anthropic` (или `openai`) | выбор провайдера |
| `MODUS_ADVISOR_MODEL=claude-haiku-5-5` | имя модели |
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` | ключ; в репозиторий, журнал и ответы API не попадает |
| `MODUS_ADVISOR_ALLOW_REMOTE=true` | согласие: тексты уходят за пределы компании, и это платно |
| `MODUS_ADVISOR_ALLOW_REAL_DATA=true` | второе, отдельное согласие для запуска **вне демо** (без `MODUS_DEMO_LOGIN=true`): в облако уйдут реальные данные сотрудников |

Сейчас решение владельца распространяется на демо-данные. Для пилота с реальными людьми второе согласие остаётся за владельцем.

## Где модель используется
Одна настройка обслуживает все места, где нужен ИИ: AI-Архивариус, «Оценка ИИ» решения, разбор протокола, находки совещания. Общение с провайдерами идёт через один переходник (`modelFetch`): запрос и ответ приводятся к одной форме, поэтому проверки после ответа (точные цитаты, схема, ссылки только на показанные кандидаты) одинаковы для локальной и облачной модели.

## AI-Архивариус
`POST /knowledge/:id/helper/ai`. Модель получает карточку знания и кандидатов, найденных тем же поиском, что и помощник без ИИ (то есть только то, что читателю и так видно), и возвращает: суть, вывод «готово / доработать», повторы, противоречия, где применить, чего не хватает. Ссылки вне списка кандидатов отбрасываются. Запускают только те, кто ведёт знания (Архивариус, ведущий, решающий, администратор). Ничего не сохраняется, уровень знания не меняется.

## Что видит человек
Каждый ответ подписан: какая модель отвечала и что текст был отправлен за пределы компании. В статусе советника — то же. Без модели — «не подключён»; шаблон за ИИ не выдаётся.

## Стоимость
Claude Haiku 5.5: $0.10 за миллион входных и $0.50 за миллион выходных токенов (документация Anthropic на 12.11.2026). Один запрос оценки или заключения — доли цента.

## Ограничения
- С настоящими Anthropic и OpenAI из среды разработки не проверялось: нет ключа и доступа в сеть. Проверены форма запросов и разбор ответов на подставных ответах.
- Нет ограничения частоты запросов и учёта расходов: в демо это не критично, для пилота нужно добавить.
- Для OpenAI используется режим ответа `json_object`; модель, которая его не поддерживает, вернёт ошибку — она будет показана как есть.
- Глубина рассуждения модели Anthropic оставлена по умолчанию.
- Расшифровка речи по-прежнему только локальная.
