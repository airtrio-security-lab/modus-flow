# ADR-0025 · Русское царство — пятая цивилизация

Status: draft, feature branch.

## Исторический период
Ориентир — Москва XVI–XVII веков в период Русского царства: краснокирпичный Кремль, белокаменные соборы, золотые купола, боярские палаты и торговые ряды. Это художественная интерпретация, не научная реконструкция.

## Модель
- ID: russia. Стиль одного подразделения, а не отдельная организация или уровень полномочий.
- Малый совет: «Боярская дума».
- Титулы как декоративные обозначения: Воевода, Думный дьяк, Дьяк, Мастеровой, Богатырь (за подтверждённые достижения и только по выбору сотрудника), Житель царства.
- Стиль не зависит от гражданства, национальности, языка, религии, пола сотрудника.
- Миграция 0018 добавляет значение russia в CHECK и разрешённые значения функции смены стиля. Историю и текущие значения других отделов не изменяет.
- Монголия как действующий ранее стиль сохраняется; Рим — отдельная будущая задача.

## Интерфейс
Векторная панорама исходной разработки: web/public/media/russian-tsardom-city.svg.
Фотореалистичная иллюстрация передана отдельно в чате и пока не входит в репозиторий.
Общий компонент CivilizationPanorama поддерживает Камелот и Русское царство.
В Русском царстве доступны 8 точек: Кремль (развитие), Государев Архив, Боярская дума, Книжные палаты, Воинская палата (личные мысли), Приказная палата (сотрудники), Ремесленный двор (задачи), Торговая площадь (инициативы). Все действия через действующие маршруты, существующие роли и права.
Облака, дымка, дым стилизованы CSS, не перехватывают касания, отключаются при prefers-reduced-motion.

## Проверки перед merge
1. Миграция поверх существующей базы без сброса и потерь.
2. Смена стиля уполномоченным главой/админом; проверка аудита; посторонний не может.
3. XP, права, задачи и история после смены стиля неизменны.
4. Восемь кликабельных зданий, клавиатура, мобильная прокрутка, reduced-motion.
5. TypeScript + Vite + интеграционные тесты.
