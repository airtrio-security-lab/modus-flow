# ADR-0038 · Бесшовный мир: возврат из здания туда, откуда пришёл

Status: accepted (задание владельца «Living Knowledge & Seamless World», 2026-11-13).

## Проблема

Из 3D-города человек входил в Библиотеку и, вернувшись, оказывался не там, где стоял. Причина измерена в коде:
при входе камера подлетает к зданию вплотную, а при уходе с экрана сохранялся именно этот крупный план
(`modus.w3d.view`). Ключ не был привязан к организации, выбранный отдел не запоминался.

## Решение

1. **Один контекст возврата** — `web/src/lib/worldReturn.ts`, ключ `modus.world.return` в `sessionStorage`
   (эта вкладка). В нём только навигация: организация, участие, маршрут мира (`#/kingdom` или
   `#/castles/<id>[/вкладка]`), режим, пять чисел камеры, id выбранного отдела, id здания. Имён, текстов и прав нет.
2. **Сохраняется место до подлёта.** `City3D` пишет контекст в момент входа в здание, до полёта; крупный план
   в память не попадает.
3. **Ничему сохранённому не верим.** Маршрут сверяется с белым списком; числа — конечные; контекст чужой
   организации, другого сотрудника, старше 8 часов или из будущего отбрасывается; отдел, которого сервер больше
   не возвращает, не выбирается, а ссылка на него ведёт в город (`reconcile`). При смене сотрудника контекст стирается.
4. **Путь назад один.** Оболочка (`App.tsx`) запоминает экран мира при переходе на рабочий экран и показывает над
   страницей ссылку «Вернуться в Содружество» / «Вернуться в город отдела «…»». Кнопка браузера «Назад»,
   ссылка и навигация приводят в одно и то же восстановленное место. После возврата табличка здания получает фокус.
5. **Переход — растворение, не ролик.** Только прозрачность, 200–260 мс; при `prefers-reduced-motion` и в
   облегчённом режиме перехода нет, полёт камеры равен нулю. Трансформаций нет намеренно: они «перепривязали бы»
   полноэкранный город и фиксированные панели.
6. **Права не меняются.** Контекст ничего не открывает: каждый экран по-прежнему спрашивает сервер.

Попутно исправлено: каталог Библиотеки переписывал адрес уже после того, как человек нажал «Назад».

## Проверка

`test/platform/world-return.test.ts` (8 тестов без браузера), `npm run demo:seamless` (3D, схема без WebGL,
телефон, «уменьшить движение», перезагрузка, клавиатура, чужая организация, удалённый отдел). Снимки —
`docs/demo/seamless/`.

## Ограничения (не скрываются)

Память живёт в пределах вкладки: после закрытия вкладки и повторного входа город открывается на обычном виде.
Положение прокрутки внутри экрана отдела не запоминается.
