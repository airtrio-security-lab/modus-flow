# ADR-0035 · «Проблема решена» подтверждает автор: +5 XP послу

Status: accepted (решение владельца 2026-11-13: «Подтверждает автор»). Закрывает открытый вопрос ADR-0032 о
начислении «+5 — обращение содержательно рассмотрено и проблема подтверждённо решена». ADR-0032 не
переписывается.

## Контекст

В процессе не было события «проблема решена», отличного от внедрения: `close` — административное закрытие
(дубликат), `reject` — отклонение, `merge` — решение внедрять. Начисление было выключено, чтобы не угадывать.

## Решение

Узкий проверяемый критерий (миграция `0021_envoy_problem_resolution.sql`, `problem_resolutions`):

1. Только обращение вида «проблема».
2. Только после **подтверждённого внедрения** — той же записи `xp_awards` (implementation), что дала +20. Поэтому
   отклонённое, закрытое и отозванное обращение подтвердить нельзя.
3. Подтверждает **тот, чей это вопрос**: сотрудник, от чьего имени записано обращение, иначе автор. Ни
   исполнитель, ни ведущий, ни ответственный за решение, ни администратор за него не подтверждают.
4. Один раз на обращение: запись только для добавления; повтор с тем же ключом возвращает тот же ответ,
   второе подтверждение — 409.
5. +`envoy_xp_resolution` (5) тому же человеку через единственный путь записи `app_envoy_grant`; правила
   проверяет база (триггер), сервис только спрашивает. Стадия, XP замка и права не меняются.
6. На карточке обращения — блок «Проблема решена?» с кнопкой «Да, проблема решена» только у этого человека;
   остальные видят, кто и когда подтвердил, или что подтверждение ещё не дано. В журнал аудита —
   `problem.resolution_confirmed` и `envoy.xp_awarded` без пользовательского текста.

## Ограничения (не скрываются)

- Подтверждение — слово самого человека, поднявшего вопрос: это осознанное решение владельца. Защита от
  злоупотребления — только после независимо подтверждённого внедрения, один раз и всего +5.
- Отозвать подтверждение нельзя (только добавление). Если проблема вернулась — новое обращение.
- Исторических подтверждений нет: до этой миграции их не существовало, ничего не восстанавливается.

сервис, ни напрямую в базу; тот же ключ — повтор, второе — 409; +5 тому, чей вопрос, с основанием; замок не
получает ничего; запись неизменяема; не для идеи, не для отклонённой и закрытой проблемы; «от имени» —
