# MODUS FLOW — Durable demo state v0.4
All demo requests, private drafts and contributions now share one local JSON state file. Default: data/modus-state.json, override with MODUS_DATA_FILE. Writes are queued, serialized and performed by writing a private temporary file, syncing and renaming it, then syncing the directory. Failed mutations are not committed in memory. Corrupt JSON aborts startup rather than resetting user work. Data directory is gitignored.
**Limitations:** one Node process only; no multi-instance locking, migrations, backups, encryption at rest, real identity or organization access controls. JSON file is not PostgreSQL and is unsuitable for production or sensitive employee information. Protect filesystem permissions and keep this demo private. Publication updates request, contribution and draft in one store transaction.
