# Демо: дворец, Великая библиотека и Высший Архив (ADR-0034)

Демо-данные вымышлены: «Модус Трейд — демо», записи о складе и сервисе придуманы для показа.

## Запуск

```bash
./scripts/demo-local.sh
npm run demo:commonwealth     # проходит экраны и проверяет их (≈25 с); SHOTS=<папка> сохраняет снимки
```

Сценарий сам вносит недостающие знания через то же API, что и человек: урок в Летописи, метод в Библиотеке
решений, наследие в Высшем Архиве. Повторный запуск ничего не дублирует.

## Сюжет, 2 минуты

| Шаг | Кто | Что показать |
| --- | --- | --- |
| 1 | любой сотрудник | «Город» в 3D: дворец-крепость с донжоном в центре, рядом храм знаний с тремя порталами и хранилище Архива |
| 2 | он же | «Схема»: те же три здания. Навести на дворец — подсветка, свет в воротах, «Дворец Большого Круглого стола» |
| 3 | он же | Нажать на библиотеку: камера летит к зданию, открывается зал с тем же рисунком арок и тремя входами |
| 4 | он же | Войти в «Высший Архив»: шапка и адрес меняются, том с печатью показывает основания включения |
| 5 | он же | Поиск «этикет»: найдено во всех залах, у каждого тома — зал и уровень проверки. «звездолёт» — «ничего не найдено», «Очистить поиск» |
| 6 | он же | Открыть том: девять разделов чтения, паспорт знания, источники со ссылкой на обращение, летопись событий |
| 7 | он же | Урок Летописи «Почему общий чат заявок на ремонт не прижился»: отрицательный опыт сохранён и показан |
| 8 | Архивариус | Тот же том: в блоке «Действия» — только то, что сервер разрешает этой роли |
| 9 | Начальник склада | «Создать запись»: четыре шага на одной странице, видно, что обязательно и кто увидит запись |
