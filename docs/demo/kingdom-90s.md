# Демо «Королевство» за 90 секунд

Сценарий для живого показа на свежих демо-данных (`./scripts/demo-local.sh` или `npm run demo:seed`).
Все люди и данные вымышлены. Тот же сценарий автоматически проходит `npm run demo:kingdom` — им стоит
проверить ноутбук перед выходом на сцену.

Стартовое состояние: замок «Склад и логистика» — уровень 2 «Крепость», 150 XP (одно подтверждённое
внедрение +100 и подтверждённый эффект +50).

ничего не даётся. Совет советует — решает ответственный. Рейтинг — подразделений, не людей».

Имитация и план: вход — имитация SSO; ИИ-советник не подключён; интеграции с Битрикс24 и 1С — план.
