# Демо «Королевство» за 90 секунд

Один реальный сценарий через приложение: **идея сотрудника → посол → Королевский совет → аргументы →
решение ответственного → внедрение → начисление XP → развитие замка → обновление рейтинга**.
Все люди и данные вымышлены. Вход — имитация корпоративного SSO.

## Перед выходом на сцену (за 10 минут)

1. Свежие данные: `./scripts/demo-local.sh --fresh` (пересоздаёт демо-базу и запускает приложение).
2. Проверка ноутбука тем же сценарием: `npm run demo:kingdom` — должно закончиться строкой
   «Сценарий «Королевство» пройден». Тест меняет данные, поэтому **после него снова запустите
   `./scripts/demo-local.sh --fresh`** (остановив сервер Ctrl+C).
3. Два окна браузера: в первом войдите за Асель Темирову и откройте «Королевство» (карта обновляется
   сама); во втором будете переключать сотрудников («Сменить сотрудника»).
4. Резервное видео лежит рядом: `.demo/kingdom-demo.mp4` (см. «Если что-то пошло не так»).

Стартовое состояние: замок «Склад и логистика» — уровень 2 «Крепость», 150 XP (внедрение +100 и
подтверждённый эффект +50).

Что проговорить: «Опыт начисляет база данных только за подтверждённые события, одно событие — одно

Не показывать как работающее: ИИ-советник с моделью, Битрикс24, 1С УТ — это план (см. слайд
«Готовность ИИ-советника» в приложении презентации).

## Если что-то пошло не так

* **Нет сети** — ничего не нужно: приложение, база и шрифты работают локально.
* **Сломался шаг в живом показе** — сразу включить видео `.demo/kingdom-demo.mp4` (≈ 80 с, тот же
  сценарий с подписями шагов). Записать заново на свежих данных: `npm run demo:record`
  (нужен Playwright; при наличии ffmpeg создаётся и .mp4, иначе только .webm).
* **Не запускается ноутбук** — то же видео с телефона или флешки; скриншоты экранов есть в презентации.
* **Данные «испорчены» прошлым прогоном** (склад не на 150 XP) — остановить сервер (Ctrl+C) и
  `./scripts/demo-local.sh --fresh`.

Проверка этого сценария автоматически: `npm run demo:kingdom` (≈ 6 с, каждое число читается с экрана).
