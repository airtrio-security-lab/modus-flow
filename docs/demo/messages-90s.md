# Демо «Королевские послания» за 90 секунд

Последовательность владельца: **Король созывает Совет → главам замков приходят личные послания →
участник открывает послание → «Войти в Совет» → круглый стол → изучает обращение → аргумент → ответственный
решает → участники получают итог → после подтверждённого внедрения замок получает XP**.
Люди и данные вымышлены, вход — имитация SSO. Всё работает на существующих данных MODUS FLOW.

## Перед выходом

1. `./scripts/demo-local.sh --fresh`.
2. Проверка ноутбука: `npm run demo:messages` — строка «Сценарий «Королевские послания» пройден».
   Потом снова `./scripts/demo-local.sh --fresh`.
3. Заранее подайте обращение за Асель Темирову: тема «ИТ и инструменты», подразделение «Склад и логистика».
   Оно уйдёт Дмитрию (ведёт) и Айгерим (решает).

Формы обращения в демо выбраны самими людьми: Олег Киселев — «Милорд», Сауле Бекова — «Миледи».
Ерлан Касымов — Король, Айгерим Нурланова — Регент. Звания прав не дают.

## Сценарий

| Время | Кто | Действие | Что видит жюри |
|---|---|---|---|
| 0:00 | Ерлан (Король) | «Совет» → обращение Асель → «Созвать заседание с записью»: время, участники Олег, Сауле, Тимур, Айгерим → «Созвать заседание» | Заседание создано; участники получили вызов |
| 0:15 | Сауле | «Уведомления» | «Король созывает Совет» — «**Миледи**, вас призывают к Круглому столу!» |
| 0:22 | Олег | «Уведомления» | «**Милорд**, вас призывают…»: тема, кто созвал, когда, №, «почему вы», «участие ожидается», что сделать |
| 0:32 | Олег | «Подтвердить участие» → «Войти в Совет» | Круглый стол по обращению: предмет обсуждения |
| 0:40 | Олег | «Аргумент за» → «Добавить аргумент» | Аргумент в журнале с именем и временем |
| 0:50 | Айгерим | «Принять решение» → «Внедрить», исполнитель Дмитрий | Решение записано: решает ответственный, не Совет |
| 1:00 | Олег | «Уведомления» | «Решение зафиксировано: Милорд, решение … утверждено: внедрять»; деловой текст ниже |
| 1:08 | Дмитрий | «Уведомления» → «Решения и поручения» | «Получено поручение» |
| 1:15 | Дмитрий | Карточка → «Отметить как реализовано» | +100 XP замку склада (база данных, один раз) |
| 1:25 | Асель, телефон | «Уведомления» | «Замок получил XP» — читается без увеличения |

Что проговорить:
- «Послание говорит языком королевства, но под ним всегда обычный деловой текст».
- «Обращение — по званию или по выбору самого человека, а не по догадке».
- «Каждое послание — от реального события, без дублей».
- «Решения и сроки отключить нельзя».
- «Звание не даёт прав».

Деловой стиль: «Мой профиль» → «Королевские послания» → «Деловой». Заголовки становятся обычными:
«Приглашение на заседание», «Решение принято».
