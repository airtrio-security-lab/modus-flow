# Демо «Живое королевство» за 90 секунд: от слов на совете до опыта замка

Путь: **сотрудник и его звание → Совет → заседание с записью → находки → подтверждение человеком →
посол → канбан → уведомление исполнителю → внедрение → XP и развитие замка.**
Люди, данные и запись вымышлены. Вход — имитация корпоративного SSO.

**Честно о технике (сказать вслух):** движок распознавания речи и языковая модель не подключены. Для показа
используется **подготовленная** запись планёрки: голоса синтезированы (espeak-ng). К ней приложена
**подготовленная** расшифровка, с которой таймкоды совпадают. Приложение так её и помечает. Находки ищет
**шаблон без ИИ** — это тоже написано на экране. Запись с живого микрофона работает, проверена в
`npm run demo:meeting`, её можно показать отдельно.

## Перед выходом (за 10 минут)

1. `./scripts/demo-local.sh --fresh`: свежие данные. Заседание «Планёрка склада: приёмка и этикетки»
   уже созвано, и все четверо участников **сами** дали согласие (это часть демо-данных).
2. Проверка: `npm run demo:meeting` должен закончиться строкой «Сценарий заседания с записью пройден».
   Тест меняет данные, поэтому после него снова запустите `./scripts/demo-local.sh --fresh`.
3. Положите на рабочий стол файл `docs/demo/planerka-demo.ogg` (43 с).
4. Два окна браузера: окно 1 — Олег Киселев (начальник склада, организатор); окно 2 — для переключения
   сотрудников.

**Хвост, если есть 30 секунд** (тот же путь, что в `docs/demo/kingdom-90s.md`):
- Айгерим в Совете выбирает «Принять решение» → «Внедрить», исполнитель — Дмитрий. Дмитрий получает «Получено поручение».
- Дмитрий выбирает «Отметить как реализовано»: замку склада начисляется +100 XP.
- Карта перестраивает замок в «Цитадель».

Что проговорить: «Слова на совете — только черновик. Обращение появляется после подтверждения человека,
с цитатой и моментом записи. Опыт замок получает только за подтверждённое внедрение. Записи и расшифровки
видят только участники заседания — даже собственник, если его не было, их не видит».

Не показывать как работающее: распознавание речи, языковую модель, Битрикс24, 1С.

## Если что-то пошло не так

* **Нет сети** — ничего не нужно, всё работает локально.
* **Файл не загружается** — проверьте, что выбран `planerka-demo.ogg` (до 25 МБ, OGG/WebM/MP3/M4A/WAV).
* **Данные испорчены прошлым прогоном** (у планёрки уже есть запись) — остановите сервер (Ctrl+C) и
  запустите `./scripts/demo-local.sh --fresh`.
* **Ноутбук не запускается** — видео `.demo/kingdom-demo.mp4` (путь «Королевства») и скриншоты в
  презентации.
* **Пересоздать демо-запись** после правки реплик: `python3 scripts/make-demo-meeting.py` (нужны
  espeak-ng и ffmpeg).
