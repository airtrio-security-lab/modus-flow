# Демо «3D-город» и официальный набор A-001—A-020

Все люди и данные вымышлены. Набор организатора — синтетический. ИИ-анализ и распознавание речи в этом сценарии не используются; там, где они не подключены, интерфейс так и пишет.

## Запуск (локально)
Одной командой на Mac (нужны Docker/OrbStack и Node ≥ 22.18):
```
./scripts/demo-local.sh --fresh --dataset      # http://127.0.0.1:3100 → «Город»
```
Или по шагам, если база и переменные окружения уже настроены:
```
npm run demo:seed
npm run platform:import-dataset -- --demo-confirm A-004,A-008
npm run demo:start            # http://localhost:3100
npm run demo:world3d          # сквозная проверка 3D (нужен свежий сид с набором)
```
Просмотр наборов зданий без бэкенда (только для разработки): `cd web && npx vite` → `/dev/world.html?set=camelot&focus=4`.

## Защита, 90–120 секунд (вокруг A-007)
1. **Город (10 с).** Вход кладовщиком → «Город». 3D-Содружество: восемь районов четырёх цивилизаций, дворец в центре. Повернуть и приблизить.
2. **Проблема (15 с).** В поиске HUD набрать `A-007` → «Набор организатора · A-007». Карточка: «Данные между системами приходится переносить вручную», категория «Интеграции и IT», приоритет «Высокий», условный статус «Новое». Ответственный назначен правилом категории — руководитель ИТ-разработки.
3. **Маршрут (15 с).** Вернуться в город: гонец обращения стоит у ворот ИТ-района (Японский сёгунат). Статус реальный: ответа ещё нет.
4. **Ответ (20 с).** Войти руководителем ИТ-разработки, ответить по существу → гонец уходит с первой позиции. Вынести на малый совет (Зал даймё).
5. **Эскалация (20 с).** На карточке «Вынести на Большой Круглый стол», причина «затрагивает несколько подразделений». Дворец → Совет: обращение в повестке Большого совета.
6. **Решение и рост (20 с).** Показать `#/dataset`: 20 строк, исходные статусы рядом с реальными; XP только у двух строк с пометкой «демо-подтверждение». Открыть район «Закупки» → «Войти в цитадель»: замок в 3D, кнопки уровней показывают подписанный предпросмотр роста.

## Дополнительные сцены
- **A-017 (обоснованный отказ).** Автор открывает своё обращение: статус «Отклонено» и объяснение решения.
- **A-019 (запасной маршрут).** Категория без правила: обращение взял запасной ответственный — это видно в карточке набора.
- **A-005 (уточнение).** Статус «Нужно уточнение», запрос сохранён в истории.
- **A-014, A-020.** Фильтры «Все обращения» по категории и статусу, просроченные; сводка на «Обзоре».
