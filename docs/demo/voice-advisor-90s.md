# Демо «Спросить советника» за 90 секунд (ADR-0042)

Все люди и данные вымышлены. Вход — имитация корпоративного SSO.

## Два варианта показа — выбрать заранее

| | Голос подключён | Голос не подключён (по умолчанию) |
| --- | --- | --- |
| Условие | Решение владельца + ключ OpenAI + переключатели ниже | Ничего не нужно |
| Что показываем | Живой разговор голосом | Честное «Голосовой AI не подключён» и текстовый режим |
| Что говорим | «Голос и найденные факты уходят в OpenAI на время разговора; разговор не записывается» | «Голос подключается одним решением; факты уже берутся из данных сотрудника» |

**Без решения владельца голос не включаем.** Платный API и передача данных в облако — только с согласием.

## Включение голоса (только после решения владельца, только демо-данные)

```bash
export MODUS_VOICE_PROVIDER=openai
export MODUS_VOICE_ALLOW_REMOTE=true
read -rs OPENAI_API_KEY && export OPENAI_API_KEY   # ключ вводится в терминале, не сохраняется
./scripts/demo-local.sh --fresh
```

В журнале сервера должна появиться строка `voice: CLOUD OpenAI Realtime gpt-realtime, voice cedar, ≤600s`.
Ноутбук: Chrome или Safari, адрес `http://localhost:3100` (микрофон работает только на https или localhost),
гарнитура — чтобы советник не слышал сам себя.

## Сценарий (голос подключён)

| Время | Кто | Что делаем | Что видит и слышит жюри |
|---|---|---|---|
| 0:00 | Олег Киселев, начальник склада | «Спросить советника» → «Начать разговор» | Боковая панель, «Слушаю», таймер |
| 0:05 | Олег, вслух | «Что сегодня требует моего внимания?» | «Думаю» → короткий ответ голосом по уведомлениям и обращениям; ссылки №… в панели |
| 0:20 | Олег, вслух, перебивает на середине ответа | «Стоп. Какие обращения склада просрочены?» | Советник замолкает сразу, отвечает на новый вопрос |
| 0:35 | Олег, вслух | «Напомни, почему отклонили предложение по логистике» | Ответ с обоснованием решения из карточки; ссылка на обращение |
| 0:50 | Олег, вслух | «Утверди обращение номер 8» | «Утверждать голосом нельзя — это делается на экране» (инструмента нет, сервер вернул ошибку) |
| 1:00 | Олег, вслух | «Подготовь черновик: резервный слот у рампы для опоздавших» | Карточка «Черновик · не сохранён» и кнопка «Сохранить черновик» |
| 1:10 | Олег | «Совет» → любой вопрос → «Спросить советника о вопросе №…» → «Расскажи суть и риски» | Суть, доводы, варианты, похожие случаи; «решает ответственный, не я» |
| 1:25 | Олег | «Завершить» | Микрофон выключен, «Разговор завершён» |

## Сценарий (голос не подключён)

| Время | Что делаем | Что видит жюри |
|---|---|---|
| 0:00 | «Спросить советника» | «Голосовой AI не подключён» — без имитации разговора |
| 0:10 | «Спросить текстом» → «Что сегодня требует моего внимания?» | Найденные записи со ссылками; пометка «без пересказа ИИ» (или ответ модели MODUS ADVISOR, если она подключена) |
| 0:25 | «Найди обращения про космодром на Луне» | «В доступных вам данных MODUS FLOW ничего не нашлось» |
| 0:35 | Ссылка №… | Открывается карточка обращения |
| 0:45 | «Совет» → вопрос → «Спросить советника о вопросе №…» | Панель за круглым столом с контекстом вопроса |
| 1:00 | Телефон (или окно 375 px): кнопка над панелью разделов, лист снизу | Разделы остаются нажимаемыми |

Что проговорить: «Советник не отвечает по памяти: каждый факт — из MODUS FLOW, с правами этого
сотрудника. Чужой отдел другой организации он не увидит. Менять данные голосом нельзя — только
подготовить черновик, который человек сохраняет сам. Живой разговор — не запись совещания: запись идёт
отдельным экраном с согласием всех».

## Если что-то пошло не так
- «Доступ к микрофону запрещён» — разрешить микрофон для localhost в настройках браузера → «Переподключить».
- «Голосовой сервис OpenAI вернул ошибку 401/429» — ключ не принят или лимит провайдера: переходим на «Текстом».
- «У вас уже идёт разговор» — закрыть панель в другой вкладке или подождать 10 минут.
