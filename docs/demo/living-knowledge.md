# Сценарий для хакатона: «Как предложение инженера стало полезным методом для всей компании»

Все данные сценария — **синтетические, учебный пример**; это написано в самих текстах обращений и знания.
Автоматическая проверка тех же 15 шагов через реальные API: `npm run demo:living` (снимки — `docs/demo/living-knowledge/`).

Подготовка: `./scripts/demo-local.sh --fresh --dataset`, открыть http://127.0.0.1:3100. Сотрудники переключаются
кнопкой «Сменить сотрудника».

| № | Кто | Что делает на экране | Что подтверждает сервер |
| --- | --- | --- | --- |
| 1 | Сервисный инженер | «Город» — 3D-карта Содружества | — |
| 2 | Сервисный инженер | «Подать обращение» → «Предложить улучшение», тема «ИТ и инструменты» | обращение создано, ответственный назначен правилами |
| 3 | Сервисный инженер | «Город»: его посол на дороге | посол приходит из `/kingdom` |
| 4 | Руководитель ИТ-разработки | «Уведомления» → обращение | уведомление `idea_published`, он — ведущий |
| 5 | Руководитель ИТ-разработки | «Совет» → обращение: довод «за», рекомендация «пилот» | записи Совета |
| 6 | Операционный директор | обращение → «Принять решение: внедрять», исполнитель — Системный аналитик | решение; ведущему в нём отказано |
| 7 | Руководитель ИТ-разработки | «Измерить эффект внедрения» | измерение начато; автору в этом отказано |
| 8 | Системный аналитик | «Добавить результат»: «до» 96 мин, «после» 72 мин, условия сопоставимы | два доказательства, эффект −25% |
| 9 | Системный аналитик, затем Операционный директор | «Изменение внедрено»; директор подтверждает эффект | внедрение и результат; автору и ведущему отказано |
| 10 | Сервисный инженер | «Город» → своя карточка: опыт посла вырос | опыт замка и посла — из журналов подтверждённых событий, один раз |
| 11 | Руководитель ИТ → Архивариус → Операционный директор | обращение → «Сохранить опыт в Библиотеку» → «Предложить» → Архивариус принимает → «Открыть организации» | знание на уровне «Библиотека решений» |
| 12 | Кладовщик | «Город» → Великая библиотека → поиск «контрольный список» | точное число найденного |
| 13 | Кладовщик | знание → «Путь решения» → «Применить этот метод» | путь собран из фактов обращения №… |
| 14 | Кладовщик | «Создать обращение на основе метода» | обычное обращение со ссылкой; «Применение ещё не подтверждено»; XP не начислен |
| 15 | Кладовщик | «Вернуться в Содружество» | камера там же, где он её оставил; его новый посол в пути |

Что стоит сказать вслух: кнопка не делает метод «применённым» и не даёт опыта — применение подтверждается
внедрением и записью куратора; отклонённые варианты остаются в пути решения; источник, закрытый для читателя,
виден только как закрытая ветвь.

Если 3D на устройстве показа недоступен или медленный: переключатель «Схема» — тот же сценарий без WebGL;
шаг 15 возвращает в схему с тем же выбранным отделом.
