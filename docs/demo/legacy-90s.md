# «Наследие Королевства» — демонстрация за 90 секунд

Свежая база с демо-данными (`npm run demo:seed` на пустой базе), сервер на :3100. Всё прогоняется автоматически: `npm run demo:legacy`
(Chromium, ~14 с; снимки — `SHOTS=<папка>`). Люди и данные вымышленные.

| # | Кто | Что показать | Что это доказывает |
|---|---|---|---|
| 1 | Олег Киселев, начальник склада | Заседание «Планёрка: этикетки у ворот»: согласие каждого, письменный протокол. Кнопка «Внести итог в Летопись» | Источник — реальное заседание |

| 3 | — | Решение «внедрять» и отчёт о внедрении по обращению | Подтверждённый результат — запись из процесса, не из библиотеки |
