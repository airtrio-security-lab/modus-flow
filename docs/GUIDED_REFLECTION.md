# Guided Reflection · MODUS FLOW
A one-question-at-a-time, private-first reflection UI replaces six simultaneous form fields. The prompts distinguish observation from hypothesis, evidence, proposal, risks, and pilot. The author can skip steps, revise privately and publish only a separately constructed snapshot.
No LLM or Notion integration is present. This is a deterministic guided interview, not an AI conversation. API usage is limited to explicit saves rather than each keystroke. The UI uses textContent for user-generated text.
Next: persistence, proper identity, real chat with explicit consent, privacy classifications, and transaction-safe publication. Demo-only, not production.
