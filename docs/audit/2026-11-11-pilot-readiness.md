## 1. Что работает без заглушек

Работает в приложении на PostgreSQL и проверено тестами или сквозными сценариями в браузере.

* **Путь обращения.** Подача → маршрутизация → Совет → решение ответственного → поручение → внедрение →
  XP замка (идемпотентно, один раз) → уровень → рейтинг подразделений.
* **Звания** отдельно от должности и прав. Король, Регент, главы замков, гильдии; настраивает администратор.
  Прав звание не даёт.
* **Заседания Совета:**
  - созыв, дата, перенос, отмена, изменение состава, «приду / не могу»;
  - личное согласие каждого: без согласия всех база не даёт начать запись;
  - письменный протокол без записи;
  - запись с микрофона в браузере (индикатор, пауза, стоп, повтор при сбое сети) или загрузка файла;
  - хранение только для участников.
* **Находки:**
  - 11 типов по шаблону, с цитатой, моментом записи ▶, говорящим (только по точной подписи в расшифровке),
    уверенностью и основанием;
  - подтверждение человеком → обычное обращение;
  - повторный анализ без дублей.
* **Сроки хранения** аудио 30 дней и расшифровок 90 дней — настраиваются организацией.
  - Удаляет только администратор, с причиной.
  - Законное удержание.
  - Неизменяемый журнал.
  - Повторное удаление после восстановления из резервной копии.
* **«Королевские послания»:**
  - обращение по званию или выбору самого человека, деловой стиль;
  - вызов к Круглому столу с фактами и кнопками;
  - итоги решения участникам Совета, «приближается срок», «замок получил XP»;
  - обязательные послания отключить нельзя;
  - центр уведомлений с фильтрами, читается на телефоне.
* **Распознавание речи — локальный faster-whisper.**
  - Проверено на настоящей русской речи: качество — в `docs/audit/asr/README.md`.
  - Подключение проверено сквозным прогоном через приложение.
  - Модель скачивается один раз; дальше запись не покидает компьютер.
* **Шлагбаум проверок.**
  - Сборка, коммит и отправка останавливаются на первом падении.
  - Проверено заведомо падающим тестом.
