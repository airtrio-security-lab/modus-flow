## Что не сделано и почему

* Нет облачной языковой модели: платные API не подключаются без разрешения владельца.
* Локальная модель (Ollama) поддержана в коде, но здесь её запустить нельзя; проверена заглушкой. Перед
  показом с моделью её нужно установить на демо-ноутбук и проверить на тестовом протоколе.
* Нет сводки обсуждения, рисков и вопросов к Совету от модели — это задачи следующего этапа.
* Импорт файлов протокола (.docx, .pdf, аудио) не сделан: только вставка текста.

npm test                         # 199 тестов, из них 11 — советник
./scripts/demo-local.sh --fresh  # затем в другом окне:
