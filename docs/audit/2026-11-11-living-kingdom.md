## Регрессия из раздела XII — где проверено

Все проверки ниже — в `test/platform/meetings.test.ts`, кроме отмеченной.

* **Сотрудник видит только своё.** Расшифровки, находки и записи закрыты для руководителя, не бывшего на
  заседании, и для другой организации. В браузере собственник не видит чужого заседания и цитаты на
  карточке.
* **Чужая задача.** Сотрудник не может отметить внедрение за исполнителя; прямой UPDATE запрещён.
* **Повторная обработка аудио.** Тот же текст даёт ту же расшифровку, тот же метод — те же находки. Те же
  слова из другого анализа отклоняются с номером уже созданного обращения.
* **Повторные XP.** +100 и +50 ровно по одному разу; повтор по тому же ключу отдаёт сохранённый ответ,
  новый — отклоняется.
* **Подмена уведомления.** Отклоняется и через функцию (не организатор), и прямой вставкой.
* **Ошибочная атрибуция говорящего.** Человек привязывается только по точному имени участника; иначе
  остаётся «не сопоставлен». Модель говорящего не назначает.
* **Запись без согласия.** Отказ в приложении и в базе. Чужое согласие поставить нельзя; после начала
  записи согласие зафиксировано.
* **Неавторизованный доступ к расшифровке.** Закрыт RLS-политикой, которая сильнее правила «руководители
  читают протоколы».
* **Ошибки AI-интеграции.** Движок или модель недоступны, ответ в неверном формате — понятная ошибка, ничего
  не сохраняется наполовину.
* **Вредоносные инструкции в расшифровке.** Статус остаётся «предложено», XP и назначений нет, выдуманные
  цитаты и неизвестные типы отброшены.
* **Звание.** «Король» не даёт сотруднику прав; звания пишет только администратор.

## Какие функции используют реальные сервисы

* Работают без внешних сервисов: PostgreSQL, браузерная запись микрофона, хранение и воспроизведение.
* Распознавание речи и языковая модель — не подключены. В коде есть только бесплатные локальные варианты,
  проверенные заглушками:
  - распознавание — локальный OpenAI-совместимый сервер, например faster-whisper-server;
  - анализ — Ollama.
* Платные API не подключались.
