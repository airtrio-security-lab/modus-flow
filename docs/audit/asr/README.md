# Проверка локального faster-whisper на русской речи — 11 ноября 2026

Решение владельца: для пилота — локальный faster-whisper, бесплатно и без отправки записей наружу.
Ниже то, что реально запускалось, и какие из этого выводы.

## Как проверяли

* **Речь — настоящая.** Взят набор FLEURS (Google, CC-BY 4.0), русский, тестовая часть: 775 записей, много
  дикторов, мужские и женские голоса, эталонные тексты.
* **«Совещания».** Из реплик разных дикторов собраны 3 «совещания» по 8 реплик с чередованием голосов,
  ≈ 70 с каждое. В каждом условии — 366 слов эталона.
* **Четыре условия:**
  - чистая запись;
  - фоновые разговоры (гомон из 4 других записей), SNR 10 дБ;
  - гомон + гул 50 Гц + широкополосный шум, SNR 5 дБ;
  - перебивания: реплики накладываются на 0,8 с, плюс гомон 10 дБ.
* **Модели** faster-whisper 1.2.1, int8, CPU 2 ядра:
  - small;
  - medium;
  - large-v3-turbo.
* **Режим и метрики.** Включён VAD, язык ru. Метрика — WER (доля ошибок в словах) после простой нормализации
  (регистр, ё→е, без пунктуации). Скорость — RTF: время обработки / длительность записи.
* **Воспроизвести:**
  ```
  python scripts/asr-eval.py fleurs --fleurs <папка FLEURS ru_ru> --models small large-v3-turbo
  ```
  Подробные результаты — в `results.json` и `turbo/results.json` (там гипотезы и эталоны).

## Результаты

| Условие | small | medium | large-v3-turbo |
|---|---|---|---|
| Чистая запись | 9,0 % | 10,1 % | **5,7 %** |
| Гомон + гул + шум, SNR 5 дБ | 16,4 % | 13,4 % | **12,6 %** |
| Фоновые разговоры, SNR 10 дБ | 44,0 % | 44,0 % | 36,9 % |
| Перебивания + гомон 10 дБ | 38,0 % | 38,8 % | 38,5 % |
| Скорость, RTF (2 ядра) | **0,2** | 0,5–1,5 | 0,3–0,5 |

Сквозная проверка через приложение (`npm run asr:smoke`) тоже прошла: 46 с настоящей речи → MODUS FLOW → локальный
сервер `scripts/whisper-server.py` (small) → расшифровка за 13,4 с, помечена «расшифровано движком small», с метками
времени.

## Что это значит

1. **Тихая комната, один говорит за раз:** 6–9 % ошибок. Для черновика, который потом проверяет человек, это
   годится — а в MODUS FLOW каждая находка и так подтверждается человеком.
   - Чаще всего ошибки в именах и терминах: «Данлопа» вместо «Данлэпа», «сунами» вместо «цунами».
   - Имена сотрудников, названия товаров и объектов будут искажаться. Человек сверяет их по записи — кнопка ▶.
2. **Фоновые разговоры и перебивания: 37–44 % ошибок.** Это не соответствует задаче, и смена модели не помогает.
   - Модель дословно записывает соседнюю речь в протокол: она слышит речь и не отличает «главную» от
     фоновой.
   - Автоматическое выделение находок на таких записях использовать нельзя.
3. **Кто говорит, faster-whisper не определяет.** Говорящий в находках появляется только из подписи в
   расшифровке. В автоматической расшифровке подписей нет, и приложение их не придумывает.
4. **Скорость на 2 ядрах.** Час совещания — около 12 минут на small и 20–30 минут на large-v3-turbo. На
   8-ядерном ноутбуке или с видеокартой быстрее в разы.

## Рекомендация для пилота (без платных подключений)

* **Модель:**
  - large-v3-turbo, если на машине ≥ 8 ядер или есть видеокарта;
  - иначе small.
  - Сервер: `python scripts/whisper-server.py --model large-v3-turbo`.
* **Запись:**
  - один микрофон на столе, близко к говорящим (конференц-микрофон или телефон в центре);
  - тихая комната;
  - правило «говорит один».
* **Если совещание шумное, с разговорами в стороне:** письменный протокол без записи — уже есть в приложении —
  или ручная расшифровка.
* **Перед пилотом — полевая проверка.**
  - 2–3 настоящие планёрки, записанные с согласия всех участников, с ручным эталоном:
    ```
    python scripts/asr-eval.py pairs --dir <папка: запись + .txt>
    ```
  - Порог для автоматического режима — WER ≤ 15 %. Выше — только письменный протокол.
* **Бесплатные альтернативы — следующий шаг, здесь не проверялись:**
  - определение говорящих — pyannote: бесплатно, нужен токен HuggingFace и принятие лицензии;
  - русская модель GigaAM: открытая, по опубликованным замерам сильна на русском.

## Ограничения этой проверки

* FLEURS — **чтение вслух**, а не живой спонтанный разговор: на реальной планёрке ошибок будет больше.
* Шум и наложения смешаны программно. Записи в реальной переговорной не было.
* Выборка мала: 24 реплики, 366 слов на условие. Разница в 1–3 п. п. между моделями — в пределах случайности.
* Один процессор на 2 ядра; видеокарта не проверялась.
