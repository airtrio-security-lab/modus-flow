# Ворота показа

БисмиЛлях. Цель — не «всё зелёное», а знать, что именно проверено, чем и где, и что осталось риском.
Вердикт выдаётся только по тому, что запущено в этой сессии. Чужие и старые отчёты — не доказательство.

## Порядок

1. **Состояние.** `git status -sb`, ветка, последний коммит, незакоммиченное. Сверить с тем, что будет показано.
2. **Локальные ворота.** `npm run verify` (нужен `TEST_DATABASE_URL`). Упал шаг — стоп, вердикт «не готово».
3. **Чистый запуск показа.** `./scripts/demo-local.sh --fresh --dataset` (с `--ai` только если модель входит в показ, ADR-0028). Открывается `http://127.0.0.1:3100`.
4. **Сквозные сценарии** на свежей базе, по одному: `npm run demo:final`, `demo:world3d`, `demo:kingdom`, `demo:councils`, `demo:meeting`, `demo:messages`, `demo:legacy`, `demo:advisor`. Сценарии меняют данные: перед следующим — `--fresh`, если он этого требует (написано в шапке файла).
5. **Отклик 3D** без базы: `npm run demo:feel`.
6. **Замер на устройстве показа.** На том ноутбуке и том телефоне, с которых пойдёт показ: `#/kingdom?diag=1` → «Замер 8 с» → «Скопировать отчёт». Записать в `docs/audit/<дата>-device-perf.md`. Меньше 30 к/с — закрепить уровень ниже или показывать «Схему».
7. **Проход глазами по сценарию** `docs/demo/final-3min.md`: каждое действие руками, на экране показа, с тем масштабом и той сетью.
8. **Запасные пути.** Без сети; без WebGL (открывается «Схема»); модель ИИ не отвечает (интерфейс пишет «не подключён»); база не поднялась (есть ли запись `npm run demo:record`).
9. **GitHub CI.** Посмотреть фактический статус последнего запуска. Не запускался — так и написать.

## Вердикт

Одна строка: **ГОТОВО** / **ЕСТЬ ЗАМЕЧАНИЯ** / **НЕ ГОТОВО**. Затем таблица: шаг · команда · результат · где запускалось. Затем:

- что не проверено и почему;
- что проверено только в эмуляции или на программной отрисовке;
- риски показа и запасной ход для каждого.

Правила: локальный проход не называется проходом CI; число без условий замера не приводится; «готово» не пишется, если хотя бы один шаг 2–5 не запускался.
