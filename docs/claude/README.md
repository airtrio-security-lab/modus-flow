# Правила и навык для Claude Code (ADR-0030)

Здесь лежат заготовки, которые Claude Code подхватывает из папки `.claude/` в корне репозитория:

- `rules/*.md` — правила с областью действия по путям (`paths:` в шапке): подгружаются, только когда Claude работает с соответствующими файлами;
- `skills/demo-gate/SKILL.md` — навык «ворота показа»: порядок проверки перед демо и формат честного вердикта.

Удалённый сеанс Claude не имеет права писать в `.claude/`, поэтому включение — одно действие владельца из корня репозитория:

```
mkdir -p .claude && cp -R docs/claude/rules docs/claude/skills .claude/
```

После этого `.claude/rules/` и `.claude/skills/` можно закоммитить вместе с остальным. Пока команда не выполнена, правила — обычные документы и на работу Claude не влияют.
